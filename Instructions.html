Quick Start

Ready to begin? Click the "Get Started" button in the navigation menu to download the CANDU VR program. Follow the installation guide above for detailed step-by-step instructions.

System Requirements:

  • Windows operating system
  • VR headset (recommended but not required)
  • Minimum 4GB RAM
  • DirectX compatible graphics card
