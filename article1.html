Installation Getting Started Guide

Learn how to download, install, and launch the CANDU Virtual Reality Educational Experience on your Windows device.

How to Access the CANDU Virtual Reality Experience

To access the CANDU Virtual Reality Educational Experience, follow these simple steps:

  1. Download the Program: Click on the "Get Started" button on the homepage or in the navigation menu.
  2. Choose Your Role: A dropdown menu will appear asking if you are a student, parent, or educator. Choose the option that best describes you.
  3. Download Begins: An executable file will automatically download to your computer.
  4. Run the Installer: Click on the downloaded file to open it up.
  5. Security Warning: A popup window stating "Windows protected your PC" will appear. Simply click the "More info" text, then click "Run anyway".
  6. Administrator Permission: Another popup will ask if you give permission to allow this program to make changes to your PC. Click "Yes".
  7. Installation Setup: The installation setup will appear. Click "Next" and "Install" buttons and wait for the program to install.
  8. Launch: Once installation is complete, make sure the launch option is checked and click "Finish". The CANDU Virtual Reality Educational program will now launch.

Troubleshooting

Common Issues and Solutions:

Download Issues

If the download doesn't start automatically, try right-clicking the "Get Started" button and selecting "Save link as" or "Download linked file".

Installation Blocked

If Windows Defender or your antivirus software blocks the installation, temporarily disable real-time protection during installation, then re-enable it afterward.

Performance Issues

Ensure your system meets the minimum requirements: Windows OS, 4GB RAM, and a DirectX-compatible graphics card.
